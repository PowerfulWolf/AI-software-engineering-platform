# 用户使用指南

面向使用 ASE 交付软件需求的人。部署完成后，日常入口是本地 Web Console。
尚未安装时先请管理员按[部署手册](../operations/production-setup.md)完成配置。

## 一次需求的基本流程

1. 打开管理员配置的 Console 地址，默认是 http://127.0.0.1:8765。
2. 在“需求与交付”创建或选择 Project，再选择该需求涉及的一个或多个本地代码目录。
   目录需要已有有效 Git 提交，输入问题见 [Git 基线准备](git-baseline.md)。
3. 按需准备团队知识、项目背景和开发规范，见[知识使用](knowledge.md)。
4. 等待准备完成，与 Product Agent 讨论需求；阅读产品说明，必要时提出修改，再批准范围。
5. 按页面提示检查计划、审批并继续，查看设计、编码、QA 和 Review 进度。
6. DONE 后检查各仓候选分支/提交、QA/Review 报告和联合验收结果，按团队流程决定合并。
