# 知识上传、选择与确认

## 为需求准备知识

在“知识库”进入团队知识库或当前项目知识库，使用“导入…”上传文档。
团队知识用于通用背景，项目知识用于该 Project 的业务背景；必须遵守的开发规则应维护为规范。
导入后等待索引状态 READY，再显式选择供之后的新需求使用。上传和选择不需要重启服务。
已经准备或批准的需求保留原知识快照，修改选择不会静默改变它的输入。

## 回答待确认的知识

1. 在需求详情打开“待确认的知识”，阅读当前问题、影响和需要你决定的事项。
2. 填写解答与事实来源或决策依据，检查后点击“批准解答”。
3. 状态变为“已确认的知识 · 待继续”后，可通过“查看已确认的知识”核对已保存内容。
4. 点击需求的“继续交付”。批准解答本身不会自动恢复执行。

已经批准的问题无需重复回答；再次出现不同问题时，只处理新的事项。
历史等待提示保留原记录，不代表刚保存的解答失效。恢复失败时记录需求、错误和时间，
按[问题反馈指引](recovery.md)交给维护者。

索引诊断、管理 API 和历史兼容机制见[规划与知识运维](../operations/planning-and-knowledge.md)。
