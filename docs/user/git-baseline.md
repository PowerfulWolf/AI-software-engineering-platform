# 创建需求前准备 Git 基线

代码目录需要属于 Git 仓库，并已有至少一次有效提交。仅创建目录或执行 `git init` 还不够。
如果提示 `GIT_BASELINE_REQUIRED`，先检查是否选中了正确的仓库或模块目录。

1. 若项目尚未纳入 Git，由仓库维护者检查忽略规则和提交范围，完成首次提交；
   也可以改选已有提交的正确仓库。
2. 确认仓库已有有效 HEAD，且工作区满足平台的干净基线要求。
3. 使用正确的目录重新创建需求，等待进入可讨论状态后继续。

旧失败需求若没有冻结 Git 基线，补交源码后也不能给旧记录补写当前 HEAD。
重新创建会绑定新的提交基线，旧失败记录保留用于追溯。

错误映射、只读历史状态及验证矩阵见[Git 基线开发说明](../development/requirement-git-baseline.md)。
