# 维护期间仅查看控制台

故障实例完成维护核验和退出后，替换服务可以恢复页面读取，同时保持需求交付暂停。
页面顶部显示“维护仅查看模式”，需求、任务、已有处理记录、模型调用和恢复准备历史仍可查看。
设置与知识管理暂不开放；此提示不是缺少配置，也不要求用户重建需求。

显式 `ASE_CONSOLE_MODE=inspection` 可让服务只读启动。故障维护留下的已验证
`console-inspection.json` 同样强制仅查看；设置 `normal` 不能覆盖该记录。记录损坏时
启动拒绝，不自动转到正常模式。不要通过删除或换目录规避维护锁。

仅查看服务没有 TeamHost、Manager 执行器、队列领取、自动调度、索引或启动 reconciliation。
所有 HTTP 修改请求均返回固定中文 `SERVICE_MAINTENANCE`，并保持已有事实不变。
服务仍可通过受控服务脚本正常 stop/restart；它的 READY 仅证明本次只读服务完成收尾，
不能证明旧的未知执行已经结束，不能批准原需求继续。

恢复正常交付是后续独立的维护与用户授权操作。当前仅查看模式不承诺 K1 已能完整交付；
必须在用户要求继续后核验原执行和草稿、处理原等待，再经过独立 Coder、QA、Review。
