# Recover stopped Coder invocations without a published result

## Goal
Close the known-stopped/no-outcome recovery gap after local sleep or lease-authority loss.
Keep the original K1 Requirement/Task, complete draft, immutable UNKNOWN outcome history,
frozen permissions and independent native QA/Review gates.

## Scope
- Trusted fact-only capture records distinguish guard revocation from provider failure for future runs.
- Add an exact engineering-only same-base stopped-invocation rescue through public baseline APIs.
- Recover the current K1 from its actual complete owned-session stop, without asserting its missing cause.
- Document local sleep as observed supporting evidence, not a fabricated renewal exception/outcome.

## Acceptance
- A real guarded subprocess stops after lease guard failure; no result/verdict is published beyond the lost fence.
- Existing absent-field wire bytes/digests remain unchanged; safe reason enums never retain exception text.
- Same Task rescue requires exact native request/start/stop/historical claim, actual owned-session-empty proof,
  no output/outcome/accepted artifact/receipt, no live claim or process, and complete legal stable draft/inventory.
- A new immutable proof and exact operator engineering authorization bind the stopped run and all captured input.
- Same-base preserve-draft only, PAUSE first, separate latest-bound RESUME; ordinary work debit, no refund.
- A new claim/context/run must deliver to same candidate independent QA PASS and Review APPROVE.
- Invalid/missing/stale/foreign stop/claim/scope, live processes, unsafe/omitted ignored source,
  exhausted frozen work and automatic policy admission all refuse with existing data preserved.
- Public same-Requirement offline fixture reaches DONE and keeps the original absent outcome and
  existing stop bytes unchanged. It must first exercise a real expired guard, native child stop,
  expired-lease reclamation and a new ordinary claim entering `EXECUTION_UNCERTAIN`.
- Console operation contract 9 exposes exact stopped-run preparation and approval; older services,
  stale Project/checkpoint/plan reads, disconnected controls and incomplete operation records refuse.
- The engineering decision records one replayable `HumanActionEvent(SUPPLY_EVIDENCE)`; evaluation
  recomputation must mark this delivery as assisted rather than autonomous.
