# Design

See .trellis/spec/core/http-knowledge-rejection-recovery.md for executable contracts, matrix
and public seams. Two independent implementation slices: route-aware knowledge completion;
existing generic-wait collector/fence plus authenticated latest accepted-progress input.
Root owns docs, integration, isolated serial tests, controlled service deployment and exact
public K1 recovery. A different agent reviews final implementation and evidence.

Optional current_draft_sha256 names a separately sealed complete present snapshot. Old absent
fields retain wire/hash compatibility. Handle cannot automatically approve it; exact trusted
Resolve does. Revalidate again before successor provider admission and include the records in
typed physical deletion. Regenerate Schemas idempotently. No error-message retry routing.
