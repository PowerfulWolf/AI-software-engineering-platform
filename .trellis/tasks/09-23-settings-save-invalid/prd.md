# 设置保存报错诊断与修复

目标：修复新版设置页连接旧版 Web Console 进程时，保存任意配置都返回 `Settings input is invalid.` 的问题；保持密钥 write-only、模型路由精确身份和原有安全校验。

验收：当前服务返回 Settings 契约版本；新版页面面对旧服务时在提交前显示明确的重启提示，不发送 PUT，不丢草稿；重启后可正常保存；真正无效的配置仍被拒绝。只跑受影响测试，不跑全量测试。

范围与回滚：按诊断结果限定在 Settings 渲染/提交、配置验证、Web Console 入口及对应测试/规范；不直接改写当前生产配置或密钥。回滚点为本次提交，存量数据处置须在交付时明确。
