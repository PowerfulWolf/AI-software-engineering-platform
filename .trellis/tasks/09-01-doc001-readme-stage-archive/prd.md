# DOC001 — Update README and archive completed stages

## Goal

让新读者能从 README 准确理解当前已经完成的能力、尚未完成的边界和最短使用路径，并建立
一个不依赖 Agent 会话的阶段归档，记录 T001–T017 的成果、验证和提交证据。

## Acceptance criteria

- README 展示当前阶段、质量基线、可用能力、限制和文档导航；
- Archive 明确区分当前状态、未来路线和已完成历史；
- T001–T017 按阶段记录目标、交付结果、不变量、验证基线和提交；
- 不把 ProjectProfile、tool protocol、真实项目 E2E 或 dashboard 描述为已完成；
- 所有 Markdown 链接和格式检查通过。
