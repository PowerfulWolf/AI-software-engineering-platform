# Design

Extend the existing trusted Coder Python launcher and writable run-root cache ownership, without weakening failed workspace comparison. Allocate pytest-cache alongside mypy-cache. Supply only the fixed cache_dir override through PYTEST_ADDOPTS in the invocation environment, and rebind it inside the immutable bootstrap before user code starts. Do not inherit host options. Quote the option value for paths containing spaces. Explicit argv overrides retain normal pytest semantics and obtain no new source write permission.

Current K1 has a real final failed stop with an empty owned session, a final POLICY outcome and released claims. Same-Task stopped_failure_retry is inapplicable. Existing terminal RecoveryPlan may retain the complete lawful scene in a new internal Task under the original Requirement; prepare and independently inspect that exact plan after deployment. No new public requirement or synthetic history is needed.
