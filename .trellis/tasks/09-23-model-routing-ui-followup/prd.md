# 模型路由与 Agent 分配界面修正

目标：保持设置页的紧凑一致性，同时让模型目录、Agent 备用分配与 Status 类型展示准确可用。

范围与验收：

1. Agent 列表行只展示名称和路由摘要；每个 Agent 的解释收进右上角可访问的信息按钮，点击可查看，不因说明长短改变行高。
2. 单 Agent 展开详情恢复横向主模型字段：标签与下拉框在同一行且垂直对齐；备用模型列表与新增入口共享合理左边界，窄屏不溢出。已用完全部启用路由时，仍提供清楚的新增路径，不允许重复路由。
3. Status 的 Responses API 路由显示“Responses API”，Codex CLI 显示实际连接方式；真正缺失的历史信息才显示“连接方式未记录”。
4. 可用模型目录初始全部折叠；添加路由只展开新增项，移除项不意外展开其他项。

允许路径：`team_view/app.js`、`team_view/style.css`、受影响的 Team View 测试和 `.trellis/spec/core/web-console.md`、本任务记录。无需更改持久化配置、模型路由身份、后端 API/Schema。
