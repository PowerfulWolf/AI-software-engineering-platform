# 设计与诊断计划

- 参考 `0481fa0` 的横向主模型字段，不直接回滚新版本的精确路由身份、帮助弹层与备用模型排序按钮。主模型行显式统一标签/控件基线；备用行与添加入口保持同一内容边界。
- Agent 职责说明使用现有 `settingsHelp` 组件；按钮在 `<summary>` 内必须阻止披露切换，保留键盘、展开状态和关闭路径。
- 对所有已分配路由的 Agent 保留“添加备用模型”位置，解释无可用候选，并提供跳转至新路由草稿的动作；新路由完成配置且启用后仍通过原有精确身份选择为备用，不能自动产生重复策略。
- Status 展示兼容两类只读数据形状：模型目录 `kind`，运行诊断 `route_kind`；空缺历史 Codex CLI transport 不猜测。
- 模型目录初始展开索引为 `null`；“添加路由”只设置新索引；关闭或移除后不替用户展开其他行。

测试先行：浏览器回归捕捉行高/对齐、候选用尽后的入口与添加路径、默认折叠；DOM 回归捕捉 Status 的 `kind=responses`。确认测试先红后修改代码。
