# Design

Use the exact Plan-frozen progress identity plus the complete already approved capture and
inventory, rather than weakening ordinary progress validation. `BaselineInitialWorkspaceAdmission`
continues to check original Task, source/base, binding, permissions and claimed worktree.
Any newer progress remains bound to its own full changed-file inventory.

The existing failed work8 has a real invocation boundary and failed outcome but no main
provider execution. It cannot use the no-invocation recovery kind and must not be assigned
a synthetic native stop. Derive a separate read-only typed proof from the supported trusted
adapter's exclusive pre-provider refusal, the complete unique route result, exact sealed
start/outcome/Context/claim and current Plan/progress/draft. Independently replay the old
gate's specific mismatch and the corrected gate's success. Scan complete exact lanes for
contradictions. Missing or ambiguous proof leaves the work waiting for engineering.

Add `RejectedWorkspaceAdmissionEvidence` to investigation and resolution and the single
action `RETRY_REJECTED_WORKSPACE_ADMISSION`. The public Handle path binds current intent,
source/checkpoint/disposition, recollects the proof and consumes one ordinary work attempt.
Atomic fenced replacement creates a fresh WorkItem, claim, Context and Run. Original failed
history, accepted artifacts and frozen budgets remain. Current capacity/admission still
run before provider invocation. QA and Reviewer stay independent.

Executable fields, validation matrix, required negative/public tests, data treatment and
rollback are specified in `.trellis/spec/core/rejected-workspace-admission.md`.

Ownership: native_owned_wait_fix owns the gate and exact observer; workspace_refusal_recovery_wire
owns domain/service/queue/Schema/read/UI integration. Root owns specs, integration and real
operations. Independent run6_owned_uncertainty reviews without production writes or code edits.
The wire worker exclusively owns the isolated test database until explicitly handed back.
